# Motion capture for the girls (dev only, not shipped)

`mocap.js` in the game root is generated by `export.py` from CMU motion capture BVH files
(CMU Graphics Lab Motion Capture Database, http://mocap.cs.cmu.edu, BVH conversion by Bruce Hahne; free for any use).
BVH copies: https://github.com/una-dinosauria/cmu-mocap (files under `data/<subject>/`).

    pip install numpy
    CMU_DIR=path/to/bvh/folder python3 scripts/mocap/export.py

- `bvh.py` parses BVH and runs forward kinematics.
- `retarget.py` maps the CMU skeleton onto the game's 17-bone rig: hips, spine, chest, neck and head copy the mocap joint
  rotations; arms and legs are aimed along the mocap bone directions. Walks have their travel removed (played in place, the
  game moves the girl); standing clips keep a fixed heading. The lower foot is put on the floor every frame.
- `export.py` picks the best loop in each take (the frames whose poses match), cross-fades the seam and packs the clip as int8.
  Add a clip to `CLIPS` to bring in another take (a Mixamo FBX would need converting to BVH first, e.g. in Blender).
